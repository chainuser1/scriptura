# Trails Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Trails: an endless, steerable stream of related verses with a real reason under every verse, learning per trail on the device.

**Architecture:** A pure-function engine module (`trail_next`, `explain`, `taste`) fuses genome cosine, the topic lane, a learned 23-family preference, novelty and moods; a Python reference defines the behaviour and golden files pin the Rust port. The Dart side keeps an append-only event log per trail in `user.db`, replays it through the engine for state, prefetches a queue, and renders one calm card per verse.

**Tech Stack:** Rust (engine crate, existing JSON ABI), Python + numpy (reference, goldens), Flutter/Dart (sqlite3, existing `SearchService` isolate), Material 3 with the existing brand tokens.

**Spec:** `docs/superpowers/specs/2026-10-14-trails-design.md` (approved 2026-10-14). Read it first; this plan only adds how.

## Plan-level refinements to the spec (behaviour unchanged)

1. **State is replayed in the engine.** The spec's `trail_next` took `family_weights[23]`. Dart has no genome vectors, so it cannot replay the log into `w`. The request therefore carries `events` (verse id and action, in order) and the engine derives `w`, the liked/disliked/skipped sets and the seen set itself, then returns `family_weights` and `leans` for display. Same maths, one place.
2. **Question seeds are encoded in the engine.** `seed` accepts `{"text": "..."}` (encoded and passed through the genome head) as well as `{"verse_id": n}` and `{"genome": [568]}`.
3. **`taste` is a third operation** (events across all trails to family scores) so the Reading taste screen needs no genome data in Dart either.
4. **A Trail is a pushed full-screen route, not a sixth destination.** The bottom bar already holds five items (Material allows three to five). The return bar (spec 8.4) is what keeps a trail reachable. See "UI design".

## Execution order: the interface first

The Dart tasks depend only on `SearchRequest.raw` and the wire format, not on the Rust engine, so the owner can see and correct the
interface before any engine work. Recommended order: **1, 4, 5, 6, 7, 8, 9** (with the audit images of Task 7B), then review the
images with the owner, then **2, 3** (reference and engine), then **10**. Until the engine tasks land, the trail page runs against
the fake search service in tests and shows "search data not installed" in the app, exactly as designed.

## Global Constraints

- Local only: no network code for trail data; nothing about trails is sent anywhere (spec 2, 11).
- No text to speech; a trail is a reading feed (spec 2).
- Feedback is instant and final: no `AlertDialog` on like, skip, dislike or delete; delete uses an Undo snackbar (spec 8.1).
- One calm card: one verse, three buttons and Why; tuning controls stay behind "Tune this trail" (spec 8.1).
- Next card within 100 ms of a tap; one batch of 10 within 100 ms (V29) and 50 ms (desktop) (spec 8.1, 9).
- Reasons are never invented; topic names are never shown; works without the topics pack (spec 6, 10).
- Brand rules already in the app: primary pink only on the active control; navy/ink for structure; Inter for interface, Source Serif 4 for scripture via `scriptureStyle`.
- Every new string is plain English at a newcomer's level; no jargon (gene ids are never shown, only labels).
- `user.db` migration must be additive and refuse downgrade like the existing store; backup format stays `scriptura-user-data-v1` with new optional keys.
- Commits carry no `Co-Authored-By` trailer (owner's standing rule).

## Review Focus

Failure modes the spec implies that no single task would otherwise exercise, most likely first:

1. **A trail with no verse left to show** (small filter such as Pearl of Great Price, many dislikes): the screen must widen, then say so and offer variety; it must never show a blank card or crash. Pinned in Task 3 (engine widening) and Task 7 (empty state).
2. **Rapid tapping** (like, like, like in under a second): feedback must apply in order, each exactly once, and the queue must not duplicate or repeat a verse. Pinned in Task 6.
3. **Engine unavailable or restarting** while a trail is open (search data missing, engine restarting after a download): the card stays, the screen explains in one line, and resumes when the engine returns. Pinned in Task 6/7.
4. **A verse the content pack cannot render** (language not complete, id outside the layout): skip it silently, never crash; the log still records it as shown. Pinned in Task 6.
5. **Backup restored onto a different verse layout:** trail rows must be refused exactly like other data (existing layout contract). Pinned in Task 5.

## Design philosophy (binding on every screen in this plan)

1. **Uncluttered.** One purpose per screen. The Trail page shows one verse, three actions and Why; everything else (mood, volume,
   focus, add variety) lives behind one "Tune" control. If a screen needs a fourth thing, it goes in a sheet.
2. **Organised.** The same thing is always in the same place: actions under the card, tuning top right, return bar at the foot, Why as
   a panel or sheet. Headings use the existing text styles; spacing is 8, 12, 16, 24 only.
3. **No overflow, ever.** Every row that can grow is a `Wrap` or has `Expanded` with ellipsis; text scales with the reader's text
   size; nothing is a fixed width wider than 360 px minus margins. The audit (Task 7B) fails the build on any layout exception at
   480, 1000 and 1366 px, and the widget tests run at 360 px with large text.
4. **Responsive by breakpoint, not by device.** Narrow (under 900 px): bottom sheets, bottom bar. Wide: side panel, content column
   at most 760 px, rail already present. The same widgets serve phone, tablet and desktop.
5. **Calm and fast.** No spinners between cards, no dialogs for feedback, motion under 200 ms and off with reduce-motion.
6. **Accessible by default.** 48 px tap targets, text contrast from the theme, every control labelled, keyboard complete.

- All colours come from `Theme.of(context).colorScheme`; text contrast is covered by the existing guideline tests, extended in Task 7.

**States:** loading the first card (skeleton card, no spinner text), engine unavailable (one sentence and "Open Settings"), nothing left (Review Focus 1), offline never matters (everything is local).

`tool/make_genome_labels.py`:

```python
"""Build assets/genome_labels.json: plain labels for the 23 families and 568 genes (hand-editable afterwards).

  .venv\\Scripts\\python.exe -I tool/make_genome_labels.py [--keep-edits]
"""
import argparse
import json
import re
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
FAMILIES = {
    'A': 'Form', 'B': 'Poetic craft', 'C': 'Imagery', 'D': 'Emotion', 'E': 'Human condition', 'F': 'Divine reference',
    'G': 'Moral texture', 'H': 'Time and place', 'I': 'Voice', 'J': 'Structure', 'K': 'How it is known',
    'L': 'Relationships', 'M': 'Bodily experience', 'N': 'Abstraction', 'O': 'Movement', 'P': 'Covenant',
    'Q': 'History and language', 'R': 'Doctrine', 'S': 'Salvation', 'T': 'Teaching and use', 'U': 'Range of meaning',
    'V': 'Precision', 'W': 'Moral and legal code',
}
DROP_FIRST = {'D': 'emotion', 'E': 'condition', 'G': 'moral', 'O': 'motion', 'M': 'phenom', 'P': 'covenant'}


def label(gene_id):
    code, rest = gene_id.split('_', 1)
    words = rest.split('_')
    if DROP_FIRST.get(code[0]) == words[0] and len(words) > 1:
        words = words[1:]
    text = ' '.join(words)
    return text[:1].upper() + text[1:]


def main():
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument('--keep-edits', action='store_true', help='keep labels already in the file that differ from the rule')
    a = ap.parse_args()
    genes = [l.strip() for l in (ROOT / 'generated-artifacts/engine-pack/retrieval/gene_ids.txt').read_text('utf-8').splitlines() if l.strip()]
    out = ROOT / 'assets' / 'genome_labels.json'
    old = json.loads(out.read_text('utf-8')) if (a.keep_edits and out.exists()) else {'genes': {}}
    data = {'families': FAMILIES, 'genes': {g: old['genes'].get(g) or label(g) for g in genes}}
    out.write_text(json.dumps(data, indent=1, ensure_ascii=False), 'utf-8')
    print(f'{len(genes)} gene labels, {len(FAMILIES)} families -> {out}')


if __name__ == '__main__':
    main()
```

```python
"""Trails reference (spec docs/superpowers/specs/2026-10-14-trails-design.md, sections 5 and 6).

Pure functions of a request and the installed packs. The Rust port (engine/src/trails.rs) must return the same ordered
verse ids for every golden case; scores agree to 1e-6.
"""
import math
from pathlib import Path

import numpy as np

from similar_verses import SimilarVerses

FAMILY_WEIGHTS = {'B': 0.75, 'I': 0.5, 'N': 0.5, 'Q': 0.0, 'T': 0.75, 'U': 0.75}   # as engine/src/search.rs
REWARD = {'like': 1.0, 'skip': -0.2, 'dislike': -1.0}
LANE_K, WIDE_K = 200, 500
NEAR_DISLIKE = 0.90
LEARN, CLIP, TASTE = 0.5, 2.0, 0.3
DISLIKE_W, SKIP_W = 0.6, 0.2
TOPIC_W = 0.5
NOVELTY_BASE, NOVELTY_FOCUS = 0.1, 0.3
MOOD_MU = 0.6


def zscore(x):
    x = np.asarray(x, dtype=np.float64)
    if len(x) < 2:
        return np.zeros(len(x))
    sd = x.std(ddof=1)
    return np.zeros(len(x)) if sd <= 1e-12 else (x - x.mean()) / sd


def normalise(v):
    n = float(np.linalg.norm(v))
    return v if n <= 1e-12 else v / n


def top_k(scores, ids, rows, k):
    """Rows (indices) of the k best by (-score, verse id)."""
    rows = np.asarray(rows)
    if len(rows) == 0:
        return rows
    order = np.lexsort((ids[rows], -scores[rows]))
    return rows[order][:k]


class Trails:
    def __init__(self, retrieval_dir, topics_db=None):
        sv = SimilarVerses(retrieval_dir)
        self.sv = sv
        self.V = sv.vectors.astype(np.float32)
        self.ids = sv.verse_ids
        self.row_of = sv.row_of
        genes = [l.strip() for l in (Path(retrieval_dir) / 'gene_ids.txt').read_text('utf-8').splitlines() if l.strip()]
        self.genes = genes
        self.gene_index = {g: i for i, g in enumerate(genes)}
        self.family = np.array([ord(g[0]) - ord('A') for g in genes])
        self.sw = np.array([math.sqrt(FAMILY_WEIGHTS.get(g[0], 1.0)) for g in genes], dtype=np.float32)
        v2 = self.V.astype(np.float64) ** 2
        self.E = np.stack([v2[:, self.family == k].sum(axis=1) for k in range(23)], axis=1)
        self.Ebar = self.E.mean(axis=0)
        self.dominant = self.E.argmax(axis=1)
        self.topics = None
        if topics_db and Path(topics_db).exists():
            self.topics = sv._topics(topics_db)

    # ---- seeds, moods, state ----------------------------------------------------------------------------------------
    def seed_vector(self, seed):
        if 'verse_id' in seed:
            return self.V[self.row_of[int(seed['verse_id'])]].astype(np.float64)
        if 'genome' in seed:
            return normalise(np.asarray(seed['genome'], dtype=np.float64))
        if 'verses' in seed:
            rows = [self.row_of[int(v)] for v in seed['verses'] if int(v) in self.row_of]
            return normalise(self.V[rows].astype(np.float64).mean(axis=0))
        raise ValueError('seed needs verse_id, genome or verses (text seeds are encoded by the engine)')

    def mood_vector(self, moods):
        if not moods:
            return None
        m = np.zeros(len(self.genes), dtype=np.float64)
        for mood in moods:
            v = np.zeros(len(self.genes), dtype=np.float64)
            for g in mood:
                v[self.gene_index[g['id']]] = float(g.get('weight', 1.0)) * float(self.sw[self.gene_index[g['id']]])
            m += normalise(v)
        return normalise(m)

    def derive(self, events):
        w = np.zeros(23)
        liked, disliked, skipped, seen = [], [], [], []
        for e in events:
            v, a = int(e['verse_id']), e['action']
            if v not in self.row_of:
                continue
            if v not in seen:
                seen.append(v)
            if a in REWARD:
                w = np.clip(w + LEARN * REWARD[a] * (self.E[self.row_of[v]] - self.Ebar), -CLIP, CLIP)
            {'like': liked, 'dislike': disliked, 'skip': skipped}.get(a, []).append(v)
        return w, liked, disliked, skipped, seen

    # ---- trail_next ------------------------------------------------------------------------------------------------
    def trail_next(self, req):
        k = int(req.get('k', 10))
        focus = float(req.get('focus', 0.5))
        mood_strength = float(req.get('mood_strength', 0.5))
        events = req.get('events', [])
        w, liked, disliked, skipped, seen_events = self.derive(events)
        seed = req['seed']
        g_seed = self.seed_vector(seed)
        extras = [self.seed_vector(x) for x in req.get('extra_seeds', [])]
        V = self.V
        rows = lambda ids: [self.row_of[v] for v in ids if v in self.row_of]  # noqa: E731

        t = g_seed + sum(extras, np.zeros_like(g_seed))
        if liked:
            t = t + V[rows(liked)].astype(np.float64).sum(axis=0)
        if disliked:
            t = t - DISLIKE_W * V[rows(disliked)].astype(np.float64).sum(axis=0)
        if skipped:
            t = t - SKIP_W * V[rows(skipped)].astype(np.float64).sum(axis=0)
        t = normalise(t) if float(np.linalg.norm(t)) > 1e-12 else g_seed
        m = self.mood_vector(req.get('moods') or [])
        tp = normalise(t + 0.5 * mood_strength * m) if m is not None else t

        seen = set(seen_events) | {int(v) for v in req.get('recent', [])}
        if 'verse_id' in seed:
            seen.add(int(seed['verse_id']))
        for x in req.get('extra_seeds', []):
            if 'verse_id' in x:
                seen.add(int(x['verse_id']))
        n = len(self.ids)
        allowed = np.ones(n, dtype=bool)
        for r in rows(seen):
            allowed[r] = False
        if req.get('filter'):
            mask = np.zeros(n, dtype=bool)
            for lo, hi in req['filter']:
                mask |= (self.ids >= lo) & (self.ids <= hi)
            allowed &= mask
        near = np.ones(n, dtype=bool)
        for d in rows(disliked):
            near &= (V @ V[d]).astype(np.float64) < NEAR_DISLIKE

        cos_t = (V @ t.astype(np.float32)).astype(np.float64)
        cos_p = (V @ tp.astype(np.float32)).astype(np.float64)
        overlap = np.zeros(n)
        topic_ok = False
        if self.topics is not None:
            by_verse, postings, _meta = self.topics
            acc = {}
            sources = list(liked) + ([int(seed['verse_id'])] if 'verse_id' in seed else []) + \
                [int(x['verse_id']) for x in req.get('extra_seeds', []) if 'verse_id' in x]
            for v in sources:
                for tp_id, wt in by_verse.get(v, []):
                    acc[tp_id] = acc.get(tp_id, 0.0) + wt
            norm = math.sqrt(sum(x * x for x in acc.values()))
            if norm > 0:
                topic_ok = True
                for tp_id, x in acc.items():
                    for u, wu in postings[tp_id]:
                        r = self.row_of.get(u)
                        if r is not None:
                            overlap[r] += (x / norm) * wu

        widened = 0
        pool_k = LANE_K
        while True:
            ok = allowed & (near if widened == 0 else np.ones(n, dtype=bool))
            elig = np.flatnonzero(ok)
            cg = top_k(cos_p, self.ids, elig, pool_k)
            ct = top_k(overlap, self.ids, elig[overlap[elig] > 0], pool_k) if topic_ok else np.array([], dtype=int)
            cand = np.unique(np.concatenate([cg, ct]).astype(int))
            if len(cand) >= min(k, len(elig)) or widened >= 2:
                break
            widened += 1
            if widened == 2:
                pool_k = WIDE_K

        if len(cand) == 0:
            return {'mode': 'trail', 'hits': [], 'family_weights': w.tolist(), 'leans': self._leans(w), 'widened': widened,
                    'candidates': 0}

        zg = zscore(cos_t[cand])
        zt = zscore(overlap[cand]) if topic_ok else np.zeros(len(cand))
        taste = TASTE * ((self.E[cand] - self.Ebar) @ w)
        nov_w = NOVELTY_BASE + NOVELTY_FOCUS * focus
        recent_rows = rows([int(v) for v in req.get('recent', [])][-5:])
        if recent_rows:
            sims = (V[cand] @ V[recent_rows].T).astype(np.float64).max(axis=1)
        else:
            sims = np.zeros(len(cand))
        novelty = nov_w * (1.0 - sims)
        mood = MOOD_MU * mood_strength * zscore((V[cand] @ m.astype(np.float32)).astype(np.float64)) if m is not None else np.zeros(len(cand))
        topics_part = TOPIC_W * zt
        score = zg + topics_part + taste + novelty + mood
        order = np.lexsort((self.ids[cand], -score))
        ranked = list(order)

        cadence = max(1, int(math.floor(8 - 5 * focus + 0.5)))
        counts = np.zeros(23)
        for v in seen_events:
            counts[self.dominant[self.row_of[v]]] += 1
        picks, explore_flags = [], []
        taken = set()
        step = int(req.get('step', len(events)))
        for j in range(min(k, len(ranked))):
            choice, explore = None, False
            if (step + j + 1) % cadence == 0:
                remaining = [i for i in ranked if i not in taken]
                fams = sorted({int(self.dominant[cand[i]]) for i in remaining if int(self.dominant[cand[i]]) != 16},
                              key=lambda f: (counts[f], f))
                if fams:
                    want = fams[0]
                    choice = next((i for i in remaining if int(self.dominant[cand[i]]) == want), None)
                    explore = choice is not None
            if choice is None:
                choice = next(i for i in ranked if i not in taken)
            taken.add(choice)
            picks.append(choice)
            explore_flags.append(explore)
            counts[self.dominant[cand[choice]]] += 1

        hits = [{'verse_id': int(self.ids[cand[i]]), 'score': float(score[i]),
                 'parts': {'genome': float(zg[i]), 'topics': float(topics_part[i]), 'taste': float(taste[i]),
                           'novelty': float(novelty[i]), 'mood': float(mood[i]), 'explore': bool(f)}}
                for i, f in zip(picks, explore_flags)]
        return {'mode': 'trail', 'hits': hits, 'family_weights': w.tolist(), 'leans': self._leans(w), 'widened': widened,
                'candidates': int(len(cand))}

    def _leans(self, w):
        order = [int(i) for i in np.argsort(-w, kind='stable')[:2] if w[i] > 0.25]
        return [chr(ord('A') + i) for i in order]

    # ---- explain / taste ------------------------------------------------------------------------------------------
    def explain(self, req):
        a, b = self.V[self.row_of[int(req['a'])]].astype(np.float64), self.V[self.row_of[int(req['b'])]].astype(np.float64)
        c = a * b
        fam_sum = np.array([c[self.family == k].clip(min=0).sum() for k in range(23)])
        total = fam_sum.sum()
        families = []
        if total > 1e-12:
            for k in np.argsort(-fam_sum, kind='stable')[:3]:
                share = fam_sum[k] / total
                if share < 0.05:
                    continue
                idx = np.flatnonzero(self.family == k)
                top = idx[np.argsort(-c[idx], kind='stable')][:3]
                families.append({'family': chr(ord('A') + int(k)), 'share': float(share),
                                 'genes': [{'id': self.genes[i], 'a': float(a[i]), 'b': float(b[i])} for i in top if c[i] > 0]})
        mood_matches = []
        wanted = [g for g in req.get('mood_genes', []) if g in self.gene_index]
        if wanted:
            ranked = sorted(wanted, key=lambda g: (-b[self.gene_index[g]], g))
            mood_matches = [g for g in ranked if b[self.gene_index[g]] > 0][:3]
        return {'mode': 'explain', 'families': families, 'mood_matches': mood_matches, 'shared_terms': [], 'shared_entities': []}

    def taste(self, req):
        score = np.zeros(23)
        for e in req.get('events', []):
            v = int(e['verse_id'])
            if v not in self.row_of or e['action'] not in ('like', 'dislike'):
                continue
            score += (1.0 if e['action'] == 'like' else -1.0) * (self.E[self.row_of[v]] - self.Ebar)
        order = [int(i) for i in np.argsort(-score, kind='stable') if score[i] > 1e-9][:5]
        return {'mode': 'taste', 'families': [{'family': chr(ord('A') + i), 'score': float(score[i])} for i in order]}
```

```rust
//! Trails (spec 2026-10-14-trails-design.md sections 5 and 6). Pure functions of a request and the installed packs.
//! The behaviour is defined by tool/trails.py; test/golden/trails.json pins this port to it.

use crate::kernels::{dot_rows_f32, top_k, zscore};
use crate::search::Index;
use crate::topics::TopicIndex;
use serde_json::{json, Value};
use std::collections::{HashMap, HashSet};

const FAMILIES: usize = 23;
const LANE_K: usize = 200;
const WIDE_K: usize = 500;
const NEAR_DISLIKE: f64 = 0.90;
const LEARN: f64 = 0.5;
const CLIP: f64 = 2.0;
const TASTE: f64 = 0.3;
const TOPIC_W: f64 = 0.5;
const MOOD_MU: f64 = 0.6;
const EXCLUDED_FAMILY: usize = 16; // Q: weight 0, never dominant

pub struct TrailModel {
    family: Vec<usize>,
    e: Vec<f64>, // [n, 23] family energy
    ebar: [f64; FAMILIES],
    dominant: Vec<usize>,
    gene_index: HashMap<String, usize>,
}

impl TrailModel {
    pub fn build(index: &Index) -> Self {
        let genes = index.genes();
        let family: Vec<usize> = index.gene_ids().iter().map(|g| (g.as_bytes()[0] - b'A') as usize).collect();
        let n = index.verse_ids.len();
        let mut e = vec![0.0f64; n * FAMILIES];
        for r in 0..n {
            let row = index.genome_row(r);
            for i in 0..genes {
                let v = f64::from(row[i]);
                e[r * FAMILIES + family[i]] += v * v;
            }
        }
        let mut ebar = [0.0f64; FAMILIES];
        for r in 0..n {
            for k in 0..FAMILIES {
                ebar[k] += e[r * FAMILIES + k];
            }
        }
        ebar.iter_mut().for_each(|x| *x /= n as f64);
        let dominant: Vec<usize> = (0..n)
            .map(|r| {
                let mut best = 0;
                for k in 1..FAMILIES {
                    if e[r * FAMILIES + k] > e[r * FAMILIES + best] {
                        best = k;
                    }
                }
                best
            })
            .collect();
        let gene_index = index.gene_ids().iter().enumerate().map(|(i, g)| (g.clone(), i)).collect();
        Self { family, e, ebar, dominant, gene_index }
    }

    fn energy(&self, row: usize) -> &[f64] {
        &self.e[row * FAMILIES..(row + 1) * FAMILIES]
    }
}

fn normalise(v: &mut [f64]) {
    let n = v.iter().map(|x| x * x).sum::<f64>().sqrt();
    if n > 1e-12 {
        v.iter_mut().for_each(|x| *x /= n);
    }
}

fn norm(v: &[f64]) -> f64 {
    v.iter().map(|x| x * x).sum::<f64>().sqrt()
}

fn to_f32(v: &[f64]) -> Vec<f32> {
    v.iter().map(|&x| x as f32).collect()
}

fn dots(index: &Index, q: &[f32]) -> Vec<f64> {
    dot_rows_f32(index.genome_matrix(), index.genes(), q).into_iter().map(f64::from).collect()
}

fn seed_vec(
    index: &Index,
    v: &Value,
    text: &dyn Fn(&str) -> Result<Vec<f32>, String>,
    entity: &dyn Fn(&str) -> Vec<i64>,
) -> Result<Vec<f64>, String> {
    let genes = index.genes();
    if let Some(eid) = v.get("entity_id").and_then(Value::as_str) {
        // a person, place or group seed is the mean genome of the entity's linked verses
        let verses: Vec<Value> = entity(eid).into_iter().map(|x| json!(x)).collect();
        return seed_vec(index, &json!({"verses": verses}), text, entity);
    }
    if let Some(id) = v.get("verse_id").and_then(Value::as_i64) {
        let r = index.row_of(id).ok_or_else(|| format!("unknown verse id {id}"))?;
        return Ok(index.genome_row(r).iter().map(|&x| f64::from(x)).collect());
    }
    if let Some(g) = v.get("genome").and_then(Value::as_array) {
        let mut x: Vec<f64> = g.iter().filter_map(Value::as_f64).collect();
        if x.len() != genes {
            return Err(format!("genome must have {genes} numbers"));
        }
        normalise(&mut x);
        return Ok(x);
    }
    if let Some(ids) = v.get("verses").and_then(Value::as_array) {
        let mut acc = vec![0.0f64; genes];
        let mut count = 0.0;
        for id in ids.iter().filter_map(Value::as_i64) {
            if let Some(r) = index.row_of(id) {
                index.genome_row(r).iter().enumerate().for_each(|(i, &x)| acc[i] += f64::from(x));
                count += 1.0;
            }
        }
        if count == 0.0 {
            return Err("no known verses in the seed".into());
        }
        acc.iter_mut().for_each(|x| *x /= count);
        normalise(&mut acc);
        return Ok(acc);
    }
    if let Some(t) = v.get("text").and_then(Value::as_str) {
        let mut g: Vec<f64> = text(t)?.iter().map(|&x| f64::from(x)).collect();
        normalise(&mut g);
        return Ok(g);
    }
    Err("seed needs verse_id, genome, verses or text".into())
}

fn mood_vector(index: &Index, model: &TrailModel, moods: &Value) -> Result<Option<Vec<f64>>, String> {
    let Some(list) = moods.as_array().filter(|l| !l.is_empty()) else { return Ok(None) };
    let genes = index.genes();
    let mut m = vec![0.0f64; genes];
    for mood in list {
        let mut v = vec![0.0f64; genes];
        for g in mood.as_array().ok_or("a mood is a list of genes")? {
            let id = g.get("id").and_then(Value::as_str).ok_or("mood gene needs an id")?;
            let w = g.get("weight").and_then(Value::as_f64).unwrap_or(1.0);
            let i = *model.gene_index.get(id).ok_or_else(|| format!("unknown gene {id}"))?;
            v[i] = w * f64::from(index.sw()[i]);
        }
        normalise(&mut v);
        m.iter_mut().zip(&v).for_each(|(a, b)| *a += b);
    }
    normalise(&mut m);
    Ok(Some(m))
}

pub fn trail_next(
    index: &Index,
    model: &TrailModel,
    topics: Option<&TopicIndex>,
    req: &Value,
    text: &dyn Fn(&str) -> Result<Vec<f32>, String>,
    entity: &dyn Fn(&str) -> Vec<i64>,
) -> Result<Value, String> {
    let n = index.verse_ids.len();
    let ids = &index.verse_ids;
    let genes = index.genes();
    let k = req.get("k").and_then(Value::as_u64).unwrap_or(10).clamp(1, 50) as usize;
    let focus = req.get("focus").and_then(Value::as_f64).unwrap_or(0.5).clamp(0.0, 1.0);
    let mood_strength = req.get("mood_strength").and_then(Value::as_f64).unwrap_or(0.5).clamp(0.0, 1.0);
    let step = req.get("step").and_then(Value::as_i64).unwrap_or(0);

    // replay the log
    let mut w = [0.0f64; FAMILIES];
    let (mut liked, mut disliked, mut skipped, mut seen_events): (Vec<usize>, Vec<usize>, Vec<usize>, Vec<usize>) =
        (vec![], vec![], vec![], vec![]);
    for e in req.get("events").and_then(Value::as_array).map(Vec::as_slice).unwrap_or(&[]) {
        let (Some(id), Some(action)) = (e.get("verse_id").and_then(Value::as_i64), e.get("action").and_then(Value::as_str)) else {
            continue;
        };
        let Some(r) = index.row_of(id) else { continue };
        if !seen_events.contains(&r) {
            seen_events.push(r);
        }
        let reward = match action {
            "like" => 1.0,
            "skip" => -0.2,
            "dislike" => -1.0,
            _ => continue,
        };
        let en = model.energy(r);
        for kk in 0..FAMILIES {
            w[kk] = (w[kk] + LEARN * reward * (en[kk] - model.ebar[kk])).clamp(-CLIP, CLIP);
        }
        match action {
            "like" => liked.push(r),
            "dislike" => disliked.push(r),
            _ => skipped.push(r),
        }
    }

    let seed = req.get("seed").ok_or("seed is required")?;
    let g_seed = seed_vec(index, seed, text, entity)?;
    let extras: Vec<Value> = req.get("extra_seeds").and_then(Value::as_array).cloned().unwrap_or_default();
    let mut t = g_seed.clone();
    for x in &extras {
        let v = seed_vec(index, x, text, entity)?;
        t.iter_mut().zip(&v).for_each(|(a, b)| *a += b);
    }
    let add = |t: &mut Vec<f64>, rows: &[usize], scale: f64| {
        for &r in rows {
            index.genome_row(r).iter().enumerate().for_each(|(i, &x)| t[i] += scale * f64::from(x));
        }
    };
    add(&mut t, &liked, 1.0);
    add(&mut t, &disliked, -0.6);
    add(&mut t, &skipped, -0.2);
    if norm(&t) > 1e-12 {
        normalise(&mut t);
    } else {
        t = g_seed.clone();
    }
    let m = mood_vector(index, model, req.get("moods").unwrap_or(&Value::Null))?;
    let tp: Vec<f64> = match &m {
        Some(m) => {
            let mut v: Vec<f64> = t.iter().zip(m).map(|(a, b)| a + 0.5 * mood_strength * b).collect();
            normalise(&mut v);
            v
        }
        None => t.clone(),
    };

    // eligibility
    let mut seen: HashSet<usize> = seen_events.iter().copied().collect();
    let recent_ids: Vec<i64> = req.get("recent").and_then(Value::as_array).map(|a| a.iter().filter_map(Value::as_i64).collect()).unwrap_or_default();
    recent_ids.iter().filter_map(|&v| index.row_of(v)).for_each(|r| {
        seen.insert(r);
    });
    let mut seed_verses: Vec<i64> = vec![];
    if let Some(v) = seed.get("verse_id").and_then(Value::as_i64) {
        seed_verses.push(v);
    }
    for x in &extras {
        if let Some(v) = x.get("verse_id").and_then(Value::as_i64) {
            seed_verses.push(v);
        }
    }
    seed_verses.iter().filter_map(|&v| index.row_of(v)).for_each(|r| {
        seen.insert(r);
    });
    let mut allowed = vec![true; n];
    seen.iter().for_each(|&r| allowed[r] = false);
    if let Some(f) = req.get("filter").and_then(Value::as_array) {
        let ranges: Vec<(i64, i64)> = f.iter().filter_map(|p| Some((p.get(0)?.as_i64()?, p.get(1)?.as_i64()?))).collect();
        let mask = index.mask_from_ranges(&ranges);
        allowed.iter_mut().zip(&mask).for_each(|(a, m)| *a &= *m);
    }
    let mut near = vec![true; n];
    for &d in &disliked {
        let s = dots(index, index.genome_row(d));
        near.iter_mut().zip(&s).for_each(|(a, v)| *a &= *v < NEAR_DISLIKE);
    }

    let cos_t = dots(index, &to_f32(&t));
    let cos_p = dots(index, &to_f32(&tp));

    // topic overlap
    let mut overlap = vec![0.0f64; n];
    let mut topic_ok = false;
    if let Some(tp_index) = topics {
        let mut acc: Vec<(u32, f64)> = Vec::new();
        let add_verse = |acc: &mut Vec<(u32, f64)>, v: i64| {
            for &(tid, wt) in tp_index.vector_of(v) {
                match acc.iter_mut().find(|(a, _)| *a == tid) {
                    Some(slot) => slot.1 += f64::from(wt),
                    None => acc.push((tid, f64::from(wt))),
                }
            }
        };
        for &r in &liked {
            add_verse(&mut acc, ids[r]);
        }
        for &v in &seed_verses {
            add_verse(&mut acc, v);
        }
        let nrm = acc.iter().map(|(_, x)| x * x).sum::<f64>().sqrt();
        if nrm > 0.0 {
            topic_ok = true;
            for (tid, x) in &acc {
                for &(u, wu) in tp_index.postings_of(*tid) {
                    if let Some(r) = index.row_of(u) {
                        overlap[r] += (x / nrm) * f64::from(wu);
                    }
                }
            }
        }
    }

    // candidate pool, widening instead of failing
    let mut widened = 0;
    let mut pool_k = LANE_K;
    let cand: Vec<usize> = loop {
        let elig: Vec<usize> = (0..n).filter(|&r| allowed[r] && (widened > 0 || near[r])).collect();
        let cg = top_k(&cos_p, ids, Some(&elig), pool_k);
        let ct = if topic_ok {
            let e2: Vec<usize> = elig.iter().copied().filter(|&r| overlap[r] > 0.0).collect();
            top_k(&overlap, ids, Some(&e2), pool_k)
        } else {
            vec![]
        };
        let mut c: Vec<usize> = cg.into_iter().chain(ct).collect();
        c.sort_unstable();
        c.dedup();
        if c.len() >= k.min(elig.len()) || widened >= 2 {
            break c;
        }
        widened += 1;
        if widened == 2 {
            pool_k = WIDE_K;
        }
    };
    let leans = |w: &[f64; FAMILIES]| -> Vec<String> {
        let mut order: Vec<usize> = (0..FAMILIES).collect();
        order.sort_by(|&a, &b| w[b].partial_cmp(&w[a]).unwrap().then(a.cmp(&b)));
        order.into_iter().take(2).filter(|&i| w[i] > 0.25).map(|i| ((b'A' + i as u8) as char).to_string()).collect()
    };
    if cand.is_empty() {
        return Ok(json!({"mode": "trail", "hits": [], "family_weights": w, "leans": leans(&w), "widened": widened, "candidates": 0}));
    }

    // score
    let zg = zscore(&cand.iter().map(|&r| cos_t[r]).collect::<Vec<_>>());
    let zt = if topic_ok { zscore(&cand.iter().map(|&r| overlap[r]).collect::<Vec<_>>()) } else { vec![0.0; cand.len()] };
    let taste: Vec<f64> = cand
        .iter()
        .map(|&r| TASTE * (0..FAMILIES).map(|kk| (model.energy(r)[kk] - model.ebar[kk]) * w[kk]).sum::<f64>())
        .collect();
    let nov_w = 0.1 + 0.3 * focus;
    let recent_rows: Vec<usize> = {
        let r: Vec<usize> = recent_ids.iter().filter_map(|&v| index.row_of(v)).collect();
        r[r.len().saturating_sub(5)..].to_vec()
    };
    let mut sims = vec![0.0f64; cand.len()];
    for (j, &rr) in recent_rows.iter().enumerate() {
        let s = dots(index, index.genome_row(rr));
        for (i, &r) in cand.iter().enumerate() {
            sims[i] = if j == 0 { s[r] } else { sims[i].max(s[r]) };
        }
    }
    let novelty: Vec<f64> = sims.iter().map(|s| nov_w * (1.0 - s)).collect();
    let mood: Vec<f64> = match &m {
        Some(m) => {
            let s = dots(index, &to_f32(m));
            zscore(&cand.iter().map(|&r| s[r]).collect::<Vec<_>>()).into_iter().map(|z| MOOD_MU * mood_strength * z).collect()
        }
        None => vec![0.0; cand.len()],
    };
    let topics_part: Vec<f64> = zt.iter().map(|z| TOPIC_W * z).collect();
    let score: Vec<f64> = (0..cand.len()).map(|i| zg[i] + topics_part[i] + taste[i] + novelty[i] + mood[i]).collect();
    let mut ranked: Vec<usize> = (0..cand.len()).collect();
    ranked.sort_by(|&a, &b| score[b].partial_cmp(&score[a]).unwrap().then(ids[cand[a]].cmp(&ids[cand[b]])));

    // deterministic exploration
    let cadence = ((8.0 - 5.0 * focus) + 0.5).floor().max(1.0) as i64;
    let mut counts = [0.0f64; FAMILIES];
    for &r in &seen_events {
        counts[model.dominant[r]] += 1.0;
    }
    let mut taken: HashSet<usize> = HashSet::new();
    let mut picks: Vec<(usize, bool)> = vec![];
    for j in 0..k.min(ranked.len()) {
        let mut choice: Option<usize> = None;
        let mut explore = false;
        if (step + j as i64 + 1) % cadence == 0 {
            let remaining: Vec<usize> = ranked.iter().copied().filter(|i| !taken.contains(i)).collect();
            let mut fams: Vec<usize> = remaining.iter().map(|&i| model.dominant[cand[i]]).filter(|&f| f != EXCLUDED_FAMILY).collect();
            fams.sort_by(|&a, &b| counts[a].partial_cmp(&counts[b]).unwrap().then(a.cmp(&b)));
            fams.dedup();
            if let Some(&want) = fams.first() {
                choice = remaining.iter().copied().find(|&i| model.dominant[cand[i]] == want);
                explore = choice.is_some();
            }
        }
        let c = choice.unwrap_or_else(|| ranked.iter().copied().find(|i| !taken.contains(i)).unwrap());
        taken.insert(c);
        counts[model.dominant[cand[c]]] += 1.0;
        picks.push((c, explore));
    }

    let hits: Vec<Value> = picks
        .iter()
        .map(|&(i, ex)| {
            json!({"verse_id": ids[cand[i]], "score": score[i],
                   "parts": {"genome": zg[i], "topics": topics_part[i], "taste": taste[i], "novelty": novelty[i], "mood": mood[i], "explore": ex}})
        })
        .collect();
    Ok(json!({"mode": "trail", "hits": hits, "family_weights": w, "leans": leans(&w), "widened": widened, "candidates": cand.len()}))
}

pub fn explain(
    index: &Index,
    model: &TrailModel,
    req: &Value,
    piece: &dyn Fn(u32) -> Option<String>,
    shared_entities: &dyn Fn(i64, i64) -> Vec<Value>,
) -> Result<Value, String> {
    let a_id = req.get("a").and_then(Value::as_i64).ok_or("a is required")?;
    let b_id = req.get("b").and_then(Value::as_i64).ok_or("b is required")?;
    let ra = index.row_of(a_id).ok_or_else(|| format!("unknown verse id {a_id}"))?;
    let rb = index.row_of(b_id).ok_or_else(|| format!("unknown verse id {b_id}"))?;
    let (a, b) = (index.genome_row(ra), index.genome_row(rb));
    let c: Vec<f64> = a.iter().zip(b).map(|(&x, &y)| f64::from(x) * f64::from(y)).collect();
    let mut fam_sum = [0.0f64; FAMILIES];
    for (i, &v) in c.iter().enumerate() {
        fam_sum[model.family[i]] += v.max(0.0);
    }
    let total: f64 = fam_sum.iter().sum();
    let mut families = vec![];
    if total > 1e-12 {
        let mut order: Vec<usize> = (0..FAMILIES).collect();
        order.sort_by(|&x, &y| fam_sum[y].partial_cmp(&fam_sum[x]).unwrap().then(x.cmp(&y)));
        for &kk in order.iter().take(3) {
            let share = fam_sum[kk] / total;
            if share < 0.05 {
                continue;
            }
            let mut idx: Vec<usize> = (0..c.len()).filter(|&i| model.family[i] == kk).collect();
            idx.sort_by(|&x, &y| c[y].partial_cmp(&c[x]).unwrap().then(x.cmp(&y)));
            let genes: Vec<Value> = idx
                .iter()
                .take(3)
                .filter(|&&i| c[i] > 0.0)
                .map(|&i| json!({"id": index.gene_ids()[i], "a": a[i], "b": b[i]}))
                .collect();
            families.push(json!({"family": ((b'A' + kk as u8) as char).to_string(), "share": share, "genes": genes}));
        }
    }
    let mut mood_matches: Vec<String> = req
        .get("mood_genes")
        .and_then(Value::as_array)
        .map(|l| l.iter().filter_map(Value::as_str).filter(|g| model.gene_index.contains_key(*g)).map(String::from).collect())
        .unwrap_or_default();
    mood_matches.sort_by(|x, y| {
        let (bx, by) = (b[model.gene_index[x]], b[model.gene_index[y]]);
        by.partial_cmp(&bx).unwrap().then(x.cmp(y))
    });
    mood_matches.retain(|g| b[model.gene_index[g]] > 0.0);
    mood_matches.truncate(3);

    let mut terms: Vec<String> = Vec::new();
    for (tid, _) in index.shared_terms(ra, rb, 40) {
        if let Some(p) = piece(tid) {
            if let Some(word) = p.strip_prefix('\u{2581}') {
                let word = word.to_lowercase();
                if word.chars().count() >= 4 && word.chars().all(|ch| ch.is_alphabetic()) && !terms.contains(&word) {
                    terms.push(word);
                }
            }
        }
        if terms.len() == 5 {
            break;
        }
    }
    Ok(json!({"mode": "explain", "families": families, "mood_matches": mood_matches, "shared_terms": terms,
              "shared_entities": shared_entities(a_id, b_id)}))
}

pub fn taste(index: &Index, model: &TrailModel, req: &Value) -> Result<Value, String> {
    let mut score = [0.0f64; FAMILIES];
    for e in req.get("events").and_then(Value::as_array).map(Vec::as_slice).unwrap_or(&[]) {
        let (Some(id), Some(action)) = (e.get("verse_id").and_then(Value::as_i64), e.get("action").and_then(Value::as_str)) else {
            continue;
        };
        let Some(r) = index.row_of(id) else { continue };
        let s = match action {
            "like" => 1.0,
            "dislike" => -1.0,
            _ => continue,
        };
        for kk in 0..FAMILIES {
            score[kk] += s * (model.energy(r)[kk] - model.ebar[kk]);
        }
    }
    let mut order: Vec<usize> = (0..FAMILIES).collect();
    order.sort_by(|&a, &b| score[b].partial_cmp(&score[a]).unwrap().then(a.cmp(&b)));
    let families: Vec<Value> = order
        .into_iter()
        .filter(|&i| score[i] > 1e-9)
        .take(5)
        .map(|i| json!({"family": ((b'A' + i as u8) as char).to_string(), "score": score[i]}))
        .collect();
    Ok(json!({"mode": "taste", "families": families}))
}
```

```rust
        let text = |t: &str| -> Result<Vec<f32>, String> {
            let ids = self.tok.encode(t)?;
            if ids.len() > MAX_TOKENS {
                return Err(format!("the question has {} tokens; the limit is {MAX_TOKENS}", ids.len()));
            }
            let enc = self.enc.lock().unwrap().encode(&ids)?;
            Ok(self.index.predicted_genome(&enc.dense))
        };
        let entity = |id: &str| -> Vec<i64> { self.people.as_ref().map(|p| p.verses_of(id).to_vec()).unwrap_or_default() };
        let mut out = crate::trails::trail_next(&self.index, &self.trails, self.topics.as_ref(), req, &text, &entity)
            .map_err(|m| ("invalid_input", m))?;
        let mut parts = self.identity.as_object().cloned().unwrap_or_default();
        if let Some(t) = &self.topics {
            parts.insert("topics".into(), json!({"sha256": t.sha256, "weight": t.weight, "lane_k": t.lane_k}));
        }
        out["configuration_id"] = json!(identity::configuration_id(&Value::Object(parts), "trail"));
        Ok(out)
    }

    fn explain_op(&self, req: &Value) -> Result<Value, Fail> {
        let piece = |id: u32| self.tok.piece(id);
        let people = self.people.as_ref();
        let shared = |a: i64, b: i64| -> Vec<Value> {

                .take(3)
                .map(|id| json!({"id": id, "name": p.display(id).map(|d| d.0).unwrap_or("")}))
                .collect()
        };
        crate::trails::explain(&self.index, &self.trails, req, &piece, &shared).map_err(|m| ("invalid_input", m))
    }
```

```dart
import 'package:flutter/services.dart' show AssetBundle, rootBundle;

class Mood {
  const Mood(this.id, this.label, this.blurb, this.genes);
  final String id, label, blurb;
  final List<({String id, double weight})> genes;
}

class Starter {
  const Starter(this.id, this.title, this.blurb, this.moodId, this.question, this.icon);
  final String id, title, blurb, moodId, question, icon;
}

/// Moods, starter trails and gene and family labels: small, editable data shipped with the app.
class TrailCatalog {
  TrailCatalog._(this.moods, this.starters, this._families, this._genes);

  final List<Mood> moods;
  final List<Starter> starters;
  final Map<String, String> _families, _genes;

  static Future<TrailCatalog>? _shared;
  static Future<TrailCatalog> get shared => _shared ??= load();

  static Future<TrailCatalog> load([AssetBundle? bundle]) async {
    final b = bundle ?? rootBundle;
    Future<Map<String, dynamic>> read(String p) async => jsonDecode(await b.loadString(p)) as Map<String, dynamic>;
    return TrailCatalog.fromJson(await read('assets/trail_moods.json'), await read('assets/trail_starters.json'), await read('assets/genome_labels.json'));
  }

  factory TrailCatalog.fromJson(Map<String, dynamic> moods, Map<String, dynamic> starters, Map<String, dynamic> labels) {
    return TrailCatalog._(
      [
        for (final m in (moods['moods'] as List).cast<Map>())
          Mood(m['id'] as String, m['label'] as String, m['blurb'] as String, [
            for (final g in (m['genes'] as List).cast<Map>()) (id: g['id'] as String, weight: (g['weight'] as num).toDouble()),
          ])
      ],
      [
        for (final s in (starters['starters'] as List).cast<Map>())
          Starter(s['id'] as String, s['title'] as String, s['blurb'] as String, s['mood'] as String, s['question'] as String, s['icon'] as String)
      ],
      (labels['families'] as Map).cast<String, String>(),
      (labels['genes'] as Map).cast<String, String>(),
    );
  }

  Mood? mood(String id) {
    for (final m in moods) {
      if (m.id == id) return m;
    }
    return null;
  }

  /// The engine's wire form of a mood: `[{id, weight}, ...]`; empty for an unknown id.
  List<Map<String, dynamic>> moodGenes(String id) => [for (final g in mood(id)?.genes ?? const []) {'id': g.id, 'weight': g.weight}];

  String familyLabel(String letter) => _families[letter] ?? letter;

  String geneLabel(String id) {
    final known = _genes[id];
    if (known != null) return known;
    final rest = id.contains('_') ? id.substring(id.indexOf('_') + 1) : id;
    final t = rest.replaceAll('_', ' ');
    return t.isEmpty ? id : t[0].toUpperCase() + t.substring(1);
  }
}
```

```dart
import '../../data/trails/trail_models.dart';
import 'trail_catalog.dart';

enum ReasonKind { themes, mood, words, people, question, taste, variety }

class Reason {
  const Reason(this.kind, this.text, {this.detail = const []});
  final ReasonKind kind;
  final String text;
  final List<String> detail;
}

/// Reasons a verse is on a trail, strongest first, at most five. Only lines whose signal is present are returned.
List<Reason> buildReasons({
  required TrailCatalog catalog,
  ExplainResult? explain,
  required TrailHitParts parts,
  required List<String> sharedQuestions,
  required List<String> moodLabels,
}) {
  final out = <Reason>[];
  String lower(String s) => s.isEmpty ? s : s[0].toLowerCase() + s.substring(1);

  if (explain != null && explain.families.isNotEmpty) {
    final top = explain.families.take(2).map((f) => lower(catalog.familyLabel(f.family))).toList();
    out.add(Reason(
      ReasonKind.themes,
      'Shares themes of ${top.join(' and ')}',
      detail: [
        for (final f in explain.families)
          if (f.genes.isNotEmpty) '${catalog.familyLabel(f.family)}: ${f.genes.map((g) => lower(catalog.geneLabel(g.id))).join(', ')}',
        'Similarity is a blend of many features; these are the strongest.',
      ],
    ));
  }
  if (explain != null && explain.moodMatches.isNotEmpty && parts.mood > 0 && moodLabels.isNotEmpty) {
    out.add(Reason(ReasonKind.mood,
        'Matches your ${moodLabels.join(' and ')} mood: ${explain.moodMatches.map((g) => lower(catalog.geneLabel(g))).join(', ')}'));
  }
  if (explain != null && explain.sharedTerms.isNotEmpty) {
    out.add(Reason(ReasonKind.words, 'Shares the words ${explain.sharedTerms.take(4).map((w) => '“$w”').join(', ')}'));
  }
  if (explain != null && explain.sharedEntities.isNotEmpty) {
    out.add(Reason(ReasonKind.people, 'Also about ${explain.sharedEntities.map((e) => e.name.isEmpty ? e.id : e.name).join(', ')}'));
  }
  if (sharedQuestions.isNotEmpty) {
    out.add(Reason(ReasonKind.question, 'Both speak to: “${sharedQuestions.first}”'));
  }
  if (parts.taste >= 0.1) out.add(const Reason(ReasonKind.taste, 'Fits what you have liked so far'));
  if (parts.explore) out.add(const Reason(ReasonKind.variety, 'A step to the side, to show you something different'));
  return out.take(5).toList();
}
```

```dart
import 'package:flutter/foundation.dart';

import '../../app_controller.dart';
import '../../data/trails/trail_models.dart';
import '../../services/engine/search_models.dart';
import '../../services/engine/search_service.dart';
import 'trail_catalog.dart';
import 'trail_reasons.dart';

enum TrailPhase { loading, ready, empty, engineDown }

/// One open trail: the queue, the feedback log and the state the screen shows. The engine holds no state; every batch
/// is requested with the full event log, so reopening a trail always reproduces it.
class TrailController extends ChangeNotifier {
  TrailController({required this.app, required Trail trail, TrailCatalog? catalog})
      : _trail = trail,
        _catalog = catalog;

  final AppController app;
  Trail _trail;
  TrailCatalog? _catalog;

  TrailPhase phase = TrailPhase.loading;
  int? current;
  final List<int> history = [];
  List<String> leans = const [];
  List<double> familyWeights = List.filled(23, 0.0);
  String? reasonHint;
  String? problem;
  TrailHitParts? currentParts;

  final List<int> _queue = [];
  final Map<int, TrailHitParts> _parts = {};
  List<TrailEvent> _events = [];
  Future<void> _chain = Future.value();
  var _disposed = false;

  Trail get trail => _trail;
  TrailCatalog get catalog => _catalog!;

  @override
  void notifyListeners() {
    if (!_disposed) super.notifyListeners();
  }

  @override
  void dispose() {
    _disposed = true;
    super.dispose();
  }

  // ---- lifecycle -----------------------------------------------------------------------------------------------------
  Future<void> start() async {
    _catalog ??= await TrailCatalog.shared;
    _events = app.user.trailEvents(_trail.id);
    history
      ..clear()
      ..addAll(_distinct([for (final e in _events) if (e.action == TrailAction.shown) e.verseId]));
    if (!app.search.available) {
      phase = TrailPhase.engineDown;
      problem = app.search.unavailableReason;
      notifyListeners();
      return;
    }
    await _guard(() async {
      final last = _events.isEmpty ? null : _events.last;
      if (last != null && last.action == TrailAction.shown && _renderable(last.verseId)) {
        current = last.verseId;
        await _refill();
        phase = TrailPhase.ready;
        notifyListeners();
      } else {
        await _advance();
      }
    });
  }

  Future<void> retry() => start();

  // ---- feedback ------------------------------------------------------------------------------------------------------
  /// Feedback is applied strictly in the order it was given, so rapid taps never interleave.
  Future<void> feedback(TrailAction action) {
    _chain = _chain.then((_) => _apply(action));
    return _chain;
  }

  Future<void> _apply(TrailAction action) async {
    final v = current;
    if (v == null || _disposed) return;
    _record(v, action);
    reasonHint = switch (action) {
      TrailAction.like => 'Following your like of ${_reference(v)}',
      TrailAction.dislike => 'Moving away from ${_reference(v)}',
      _ => null,
    };
    _queue.clear();
    await _guard(_advance);
  }

  // ---- tuning --------------------------------------------------------------------------------------------------------
  Future<void> tune({List<String>? moods, double? focus, double? moodStrength, String? volume}) {
    _chain = _chain.then((_) async {
      app.user.updateTrail(_trail.id, moods: moods, focus: focus, moodStrength: moodStrength, volume: volume);
      _trail = app.user.trail(_trail.id)!;
      _queue.clear();
      await _guard(() async {
        await _refill();
        notifyListeners();
      });
    });
    return _chain;
  }

  Future<void> addSeed(TrailSeed seed) {
    _chain = _chain.then((_) async {
      app.user.addTrailSeed(_trail.id, seed);
      _queue.clear();
      await _guard(() async {
        await _refill();
        notifyListeners();
      });
    });
    return _chain;
  }

  void rename(String name) {
    final n = name.trim();
    if (n.isEmpty) return;
    app.user.updateTrail(_trail.id, name: n);
    _trail = app.user.trail(_trail.id)!;
    notifyListeners();
  }

  // ---- explanation ---------------------------------------------------------------------------------------------------
  Future<List<Reason>> why() async {
    final v = current;
    if (v == null) return const [];
    final anchor = _anchor();
    ExplainResult? ex;
    if (anchor != null && app.search.available) {
      try {
        final genes = <String>[for (final m in _trail.moods) for (final g in catalog.moodGenes(m)) g['id'] as String];
        ex = ExplainResult.fromResponse(await app.search.search(SearchRequest.raw('explain', {'a': anchor, 'b': v, 'mood_genes': genes})));
      } on SearchFailure {
        ex = null;
      }
    }
    return buildReasons(
      catalog: catalog,
      explain: ex,
      parts: _parts[v] ?? const TrailHitParts(),
      sharedQuestions: _sharedQuestions(anchor, v),
      moodLabels: [for (final m in _trail.moods) catalog.mood(m)?.label ?? m],
    );
  }

  /// The verse this card is explained against: your latest like, else the seed verse, else the previous card.
  int? _anchor() {
    for (final e in _events.reversed) {
      if (e.action == TrailAction.like) return e.verseId;
    }
    if (_trail.seed.verseId != null) return _trail.seed.verseId;
    final i = history.length - 2;
    return i >= 0 ? history[i] : null;
  }

  List<String> _sharedQuestions(int? a, int b) {
    final store = app.answers;
    if (store == null || a == null) return const [];
    final ids = store.forVerse(a, language: app.language).map((q) => q.id).toSet();
    return [for (final q in store.forVerse(b, language: app.language)) if (ids.contains(q.id)) q.text];
  }

  // ---- internals -----------------------------------------------------------------------------------------------------
  Map<String, dynamic> _request({int k = 10}) {
    final seeds = app.user.trailSeeds(_trail.id);
    return {
      'op': 'trail_next',
      'k': k,
      'step': history.length,
      'seed': _trail.seed.toEngine(),
      'extra_seeds': [for (final s in seeds) s.toEngine()],
      'events': [for (final e in _events) {'verse_id': e.verseId, 'action': e.action.name}],
      'recent': history.length <= 5 ? List<int>.of(history) : history.sublist(history.length - 5),
      'moods': [for (final m in _trail.moods) catalog.moodGenes(m)],
      'mood_strength': _trail.moodStrength,
      'focus': _trail.focus,
      'filter': _filter(),
      'language': app.language,
    };
  }

  List<List<int>>? _filter() {
    final v = _trail.volume;
    if (v == 'all') return null;
    final vols = app.repository?.volumes() ?? const [];
    List<int> range(String key) {
      final e = vols.where((x) => x.key == key).firstOrNull;
      return e == null ? const [] : [e.firstVerseId, e.lastVerseId];
    }

    final keys = v == 'bible' ? ['ot', 'nt'] : [v];
    final out = [for (final k in keys) range(k)].where((r) => r.length == 2).toList();
    return out.isEmpty ? null : out;
  }

  Future<void> _refill() async {
    final r = await app.search.search(SearchRequest.raw('trail_next', _request()));
    final b = TrailBatch.fromResponse(r);
    familyWeights = b.familyWeights;
    leans = b.leans;
    _queue
      ..clear()
      ..addAll(b.hits.map((h) => h.verseId));
    for (final h in b.hits) {
      _parts[h.verseId] = h.parts;
    }
  }

  Future<void> _advance() async {
    while (true) {
      if (_queue.isEmpty) {
        await _refill();
        if (_queue.isEmpty) {
          current = null;
          phase = TrailPhase.empty;
          notifyListeners();
          return;
        }
      }
      final v = _queue.removeAt(0);
      _record(v, TrailAction.shown);
      if (!_renderable(v)) continue;
      current = v;
      currentParts = _parts[v];
      phase = TrailPhase.ready;
      notifyListeners();
      return;
    }
  }

  Future<void> _guard(Future<void> Function() body) async {
    try {
      problem = null;
      await body();
    } on SearchFailure catch (e) {
      problem = e.message;
      phase = current == null ? TrailPhase.engineDown : phase; // the card stays when there is one
      notifyListeners();
    }
  }

  void _record(int verse, TrailAction action) {
    app.user.addTrailEvent(_trail.id, verse, action);
    _events.add(TrailEvent(verse, action, DateTime.now()));
    if (action == TrailAction.shown && !history.contains(verse)) history.add(verse);
  }

  bool _renderable(int verse) {
    try {
      app.repository!.getPassage(verse, language: app.language);
      return true;
    } on Object {
      return false;
    }
  }

  String _reference(int verse) {
    try {
      return app.repository!.getPassage(verse, language: app.language).reference;
    } on Object {
      return 'that verse';
    }
  }

  static List<int> _distinct(Iterable<int> xs) {
    final seen = <int>{};
    return [for (final x in xs) if (seen.add(x)) x];
  }
}
```

```dart
// taste_summary.dart
import '../../data/content/catalog.dart';

String tasteSentence({required List<String> familyLabels, String? volumeName}) {
  if (familyLabels.isEmpty) return 'Like a few verses on a trail and your taste will show here.';
  final fams = familyLabels.map((l) => l.toLowerCase()).join(' and ');
  return volumeName == null ? 'You lean toward $fams.' : 'You lean toward $fams, mostly in $volumeName.';
}

List<({String name, double share})> volumeShares(List<int> verses, List<VolumeEntry> volumes) {
  if (verses.isEmpty) return const [];
  final counts = <String, int>{};
  for (final v in verses) {
    for (final vol in volumes) {
      if (v >= vol.firstVerseId && v <= vol.lastVerseId) {
        counts[vol.name] = (counts[vol.name] ?? 0) + 1;
        break;
      }
    }
  }
  final out = [for (final e in counts.entries) (name: e.key, share: e.value / verses.length)];
  out.sort((a, b) => b.share.compareTo(a.share));
  return out;
}
```

```python
class Engine(BaseEngine):
```
